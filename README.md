# Quake-III-Arena-fixed-game.bat-script

That script helps you build your own .qvm from official id-Software Quake-III-Arena sources. Use him instead of default game.bat script

  1 - put this script and lcc.exe, q3asm.exe, q3cpp.exe, q3rcc.exe into the "Quake-III-Arena-master\code\game" folder
  2  - run script and find your qagame.qvm in "C:\quake3\baseq3\vm"
  3 - enjoy
